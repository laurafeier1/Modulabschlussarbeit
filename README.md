# Modulabschlussarbeit:
Dieses Repository enthält den Python-Code zur Modulabschlussarbeit für die Sarkasmuserkennung.

Das Korpus "Sarcasm Corpus V2" kann an folgender Webseite runtergeladen werden: https://nlds.engineering.ucsc.edu/sarcasm2/.
Die 3 heruntergeladenen CSV-Dateien müssen im Ordner "sarcasm_v2" abgelegt werden.

Für die Ausführung des Python-Codes werden folgende Python-Bibliotheken benötigt: pandas, numpy, scikit-learn, nltk, matplotlib.
